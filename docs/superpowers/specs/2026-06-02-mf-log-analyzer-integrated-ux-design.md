# MF-LOG-ANALYZER Integrated UX Improvement Design

## 목적

MF-LOG-ANALYZER v2 프로토타입에 분석 흐름을 완성하는 기능을 한 번에 반영한다. 사용자는 CSV를 업로드한 뒤 재생, 이벤트, 구간, 리포트, 문서, 설정을 같은 작업 흐름 안에서 다룰 수 있어야 한다.

이번 설계는 사용자가 선택한 A안, 즉 큰 묶음 통합 구현을 기준으로 한다.

## 제외 범위

다음 두 항목은 이번 구현에서 제외한다.

- CSV 업로드 직후 첫 화면 개선
- 데이터 품질 진단 강화

기존 CSV malformed row 경고, 재생 상태 유지, 기본 세션 요약은 유지하되, 새 업로드 마법사나 신뢰도 진단 대시보드는 만들지 않는다.

## 사용 시나리오

1. 사용자가 CSV를 업로드한다.
2. 기존 분석 창과 재생 도크가 열린다.
3. 사용자는 좌측 패널에서 시각화, 분석, 리포트, 문서 항목을 선택한다.
4. 시간 재생 위치는 모든 분석 창에서 공유된다.
5. 이벤트 리뷰 패널에서 이상 이벤트를 확인하고 상태와 메모를 남긴다.
6. 구간 분석 패널에서 현재 재생 범위 또는 직접 지정한 시간 범위로 분석 구간을 만든다.
7. 리포트 내보내기로 현재 세션, 이벤트 리뷰, 구간 요약을 HTML 파일로 저장한다.

## 정보 구조

좌측 패널은 기존 단일 목록을 그룹형 목록으로 바꾼다.

- 시각화: Time-Series Graph, GPS Map, G-G Diagram, 3D Vehicle Model, Current Values Table
- 분석: Data Analysis, Segment Analysis, Event Review
- 리포트: Benchmark Summary, Export Report
- 문서: Documents

우측 속성창은 현재처럼 선택된 창 기준으로만 표시한다. 설정은 공통적으로 다음 섹션 구조를 따른다.

- 표시: 창 표시 방식, 지도 배경, 오버레이 토글
- 데이터: 선택 채널, 기구학 입력, 이벤트/구간 기준
- 스타일: 색상, 선 굵기, 한계원, 강조 방식
- 고급: 캐시, 샘플링, 진단성 옵션

선택 창에 해당 설정이 없는 섹션은 표시하지 않는다.

## 이벤트 리뷰

이벤트 리뷰는 기존 재생 이벤트 목록을 분석 작업 흐름으로 확장한다.

이벤트 항목은 다음 필드를 가진다.

- 이름
- 발생 시간
- 심각도
- 관련 센서
- 값
- 감지 조건
- 리뷰 상태: 미검토, 확인, 무시
- 사용자 메모

이벤트를 선택하면 재생 위치가 해당 시간으로 이동한다. 재생 도크의 이벤트 마커도 같은 이벤트를 강조한다.

리뷰 상태와 메모는 현재 앱 세션과 `.mflogproj` 프로젝트 저장 파일에 보존한다.

## 구간 분석

구간 분석은 사용자가 시간 범위를 지정하고 구간 통계를 계산하는 기능이다.

사용자는 다음 방식으로 구간을 만든다.

- 현재 재생 위치를 시작 시간으로 지정
- 현재 재생 위치를 종료 시간으로 지정
- 숫자 입력으로 시작/종료 시간 직접 수정
- 생성된 구간 이름 변경

구간 통계는 현재 CSV 세션의 인식된 주요 센서 기준으로 계산한다.

- duration
- row count
- average speed
- max speed
- min/max RPM
- average TPS
- max absolute ax
- max absolute ay
- minimum battery voltage

센서가 없으면 해당 항목은 `-`로 표시한다. 분석 자체는 실패하지 않는다.

선택된 구간은 Time-Series Graph, GPS Map, G-G Diagram에서 가능한 범위 안에서 강조한다.

## 리포트 내보내기

리포트 내보내기는 HTML 파일을 우선 지원한다.

리포트에는 다음 내용을 포함한다.

- 파일명, row 수, 전체 길이, 샘플링 주기, 이벤트 수
- 현재 선택 채널
- 이벤트 리뷰 요약
- 구간 분석 요약
- 주요 센서 현재값 또는 마지막 재생 위치 값
- 생성 시간

파일 저장이 실패하면 앱은 세션을 유지하고 경고 메시지를 표시한다.

PDF 출력은 이번 범위에 포함하지 않는다. HTML 파일을 브라우저 또는 외부 도구로 PDF 변환할 수 있게 구조화된 마크업으로 만든다.

## 재생 도크 개선

재생 도크는 기존 기능을 유지하면서 정보 배치를 정리한다.

- 파일/row/sample/event/current row 정보는 한 줄 요약으로 유지한다.
- 재생 버튼과 속도 선택은 좌측에 고정한다.
- 타임라인과 이벤트 마커는 남은 폭을 사용한다.
- 센서 카드 영역은 좁은 화면에서 가로 스크롤을 허용한다.
- 이벤트 마커 tooltip에는 이름, 시간, 센서, 값, 조건을 표시한다.

## 앱 안정성

앱 실행 중 발생하는 예외는 로그 파일에 남긴다.

로그 위치는 사용자 홈 기준 아래 경로를 사용한다.

```text
%LOCALAPPDATA%\MF-LOG-ANALYZER-v2\logs
```

파일 저장 실패, 리포트 저장 실패, 프로젝트 저장 실패는 치명 오류로 처리하지 않는다. 상태바 또는 재생 도크 경고 라벨에 요약을 표시한다.

## 데이터 저장

`.mflogproj`에는 기존 항목에 다음 필드를 추가한다.

- event_reviews
- analysis_segments
- selected_sidebar_group
- report_output_path

스키마 버전은 `2`로 올린다. 기존 버전 1 프로젝트 파일은 기본값을 채워 열 수 있어야 한다.

## 테스트 전략

테스트는 기존 PySide6/pytest 구조를 유지한다.

- 좌측 패널 그룹 항목이 생성되는지 확인한다.
- 선택된 분석 창에 맞는 우측 속성창만 표시되는지 확인한다.
- 이벤트 리뷰 상태와 메모가 저장/복구되는지 확인한다.
- 이벤트 선택이 playback seek를 수행하는지 확인한다.
- 구간 통계가 demo session에서 계산되는지 확인한다.
- 구간 정보가 프로젝트 파일에 저장/복구되는지 확인한다.
- HTML 리포트가 세션, 이벤트, 구간 정보를 포함하는지 확인한다.
- 로그 디렉터리와 예외 기록 유틸리티가 동작하는지 확인한다.

## 수용 기준

- CSV 업로드 후 기존 분석 재생 흐름은 유지된다.
- 좌측 패널은 그룹형 정보 구조로 표시된다.
- Event Review 창에서 이벤트 상태와 메모를 편집할 수 있다.
- Event Review 창에서 이벤트 클릭 시 모든 분석 창의 재생 시점이 이동한다.
- Segment Analysis 창에서 구간을 만들고 통계를 볼 수 있다.
- 프로젝트 저장/열기 후 이벤트 리뷰와 구간 분석 상태가 복구된다.
- Export Report 메뉴 또는 리포트 창에서 HTML 리포트를 생성할 수 있다.
- 좁은 창에서도 재생 도크의 주요 컨트롤이 겹치지 않는다.
- 앱 예외/저장 실패는 로그와 사용자 경고로 남고 세션을 막지 않는다.
